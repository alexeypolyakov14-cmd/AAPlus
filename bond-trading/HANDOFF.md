## Как работает пользователь
Пользователь не запускает команды сам: он пишет в чат, ассистент запускает через GitHub Actions и пересказывает
результат по-русски. Контейнер сессии без сети: MOEX/Telegram недоступны, всё живое — только через Actions.

Запуск разовой команды: `mcp__github__actions_run_trigger(run_workflow, workflow_id=bond-trading.yml, ref=<ветка>,
inputs={"cmd": "<аргументы bondtrader>"})` — job «Разовая команда под профилем hy», профиль `configs/hy.yaml`.
Вывод: `list_workflow_jobs` → job id → `get_job_logs(job_id, return_content=true, tail_lines=N)`.
`inputs.lookup="НЛМК"` = `bondtrader why`. Аргументы с пробелами в `cmd` берутся в кавычки: `peers "Балтийский лизинг"` (шаг разбирает строку через xargs).
Другие галочки dispatch: `daily` (отчёт в Telegram), `bot` (+`bot_menu`), `telegram_setup`, `smoke` (долгий живой прогон, ~35 мин),
`execute` + strategy/profile (ребалансировка песочницы T-Invest).

Стоимость: репозиторий приватный, минуты Actions платные (пользователь поднял лимит 11.09). Долгий job live-smoke
запускается только по push в main, по расписанию или по галочке `smoke`.

  отчётность ГИР БО (книга `data/books/financials.csv`, 87 эмитентов, загружена пользователем 14.09) и e-disclosure —
  доступны ТОЛЬКО из РФ (из CI геоблок); пополняет пользователь локально (см. раздел «Отчётность ГИР БО»).
- Конвейер: сито ликвидности (`screener.py`) → стоп-факторы (дефолты MOEX, новости) → риск-фильтр (`risk.py`,
  спред ≤ 2000 б.п., листинг ≤ 3, рейтинг ≥ B) → стратегия → лимиты портфеля → ордера.
- Стратегии: `value_hy` (композит: остаток спреда к регрессии 0.40, отчётность 0.35 (пока 0), доходность−PD·LGD 0.25,
  новости 0.15), `gspread` (rank=spread|peers|model; top_n, per_issuer, min_spread_bp, min_excess_bp) — сейчас
  пользователь работает с `gspread rank=peers`.
- Группа пиров `analytics/peers.py`: рейтинг ± дюрация ±1 год (опц. сектор), каскадное расширение при <5 пиров;
  команда `peers`, `peers "<бумага>"`.
- Ключ эмитента (`models.issuer_key`): по полному названию без ОПФ; «БалтЛизП16»/«БалтЛизП18» — один эмитент.
- Валюта бумаги = FACEUNIT (валютные/замещающие отсеиваются); корпоративные линкеры (номинал > первоначального,
  купон < 5%) отсеиваются как линкеры.

  Сопоставление названий строгое двустороннее (`issuer_same`), допускается одно лишнее слово субъекта.
  Диагностика: `ratings match "<имена через запятую>"`, `ratings audit --problems`, `ratings list`.

## Перебор методологии (11.09, вечер) — что добавлено
Четыре ракурса на одну бумагу, все печатаются в обосновании `signals -s gspread` при любом `rank`:
- **пиры** (`analytics/peers.py`): ступень рейтинга ± дюрация; для бумаг БЕЗ рейтинга сначала свой сектор, потом все
  безрейтинговые (раньше суборды Сбера и Москва задавали медиану для ВДО 3-го уровня);
- **история** (`analytics/history.py` + `data/history.py`): G-спред по дням = наша математика от цены закрытия и НКД
  из MOEX history по полному графику бумаги против кривой ОФЗ той же даты (`zcyc?date=` работает, проверено 11.09:
  298 из 306 бумаг с историей). Доходность MOEX (YIELDCLOSE) НЕ используется как основная: для бумаг с офертой она
  считается к оферте и перед офертой уходит в тысячи процентов (Автоассистанс показывал 30875 б.п.) — только запасной
  путь без графика. Кривые по датам копятся в `data/zcyc_history.json` — ОТДЕЛЬНЫЙ кэш Actions `zcyc-<run_id>`
  (см. урок ниже). Метрики: медиана/MAD/z, chg30/chg60 (к уровню 30/60 дней назад), режим
  расширение/сжатие/стабильно/первичка. Окно `data.history_days` (90);
- **кривая эмитента** (`analytics/issuer_curve.py`): ориентир по остальным выпускам эмитента (leave-one-out: регрессия по
  дюрации при ≥3 выпусках, иначе медиана/единственный сосед), `vs_issuer` = спред − ориентир;
- **запаздывание рейтинга** (`cli._rating_lag`): повышение за 180 дн. без сжатия спреда за 60 дн.
Команды: `history [бумага] [--days N --top --bottom --sort chg30|z|chg60 --regime …]`, `issuer [эмитент]`,
`signals -s gspread -p rank=peers|history|issuer|model|spread`. Колонки chg30/z/hist/vs_issuer добавлены в `peers` и
`spreads`. Диагностика: строка «История спредов: N из M» в stderr job.

**Урок 11.09 (стоил пяти прогонов): список `path` в `actions/cache` входит в версию кэша.** Добавление одного файла в
список путей блока «Книги (кэш)» сделало все прежние `books-*` кэши невидимыми (в логе «Cache not found…», «файл
рейтингов не найден»), и прогоны шли без рейтингов и новостей. Список путей книг менять НЕЛЬЗЯ; новые книги — отдельным
шагом `actions/cache` со своим ключом (как `zcyc-`).

  (ключевая+5) плечо после налога вредно везде, кроме быстрого снижения. Мгновенная просадка капитала при 3x и шоке +300: −9.5%,
  стресс −15.5%. Рекомендация ассистента: не выше 1.5x и только через РЕПО с ЦК. Все доходности в отчётах — gross, если не сказано иное.
- **Урок сессии**: фоновые `sleep`-таймеры надо ждать до уведомления о завершении; пустой файл вывода ≠ истёкшее время
  (один здоровый прогон был отменён через 2.5 минуты по этой ошибке).

## Вторая ось отбора (13.09): метрики релизов против рейтинга
- **Зачем**: ранжирование по премии к пирам ставит наверх «рынок что-то знает» (АБЗ-1, Полипласт), а Гидромашсервис с +61 в хвост.

  и рейтинг из заголовка; `implied_grade` даёт ступень по бенчмаркам (нефинансовые; худшая из нагрузки и покрытия);
  `rating_gap = grade(выданный) − grade(по метрикам)`, < 0 — метрики хуже рейтинга. `analytics/quality.py` — QualityStats по срезу.
- **Команды**: `metrics fetch --from-screen [--min-rating A- --releases 3 --refresh]` (ссылки на релизы только из реестра Эксперт РА;
  НКР/АКРА-эмитенты пропускаются — 52 из 93 в ступени A), `metrics fetch --query <имена>`, `metrics list [--min-gap 0]`, `metrics show`.
  `peers` получил колонки implied/gap и `--min-gap`; `signals -s gspread -p rank=quality -p min_gap=0` — премия к пирам только у
  бумаг с метриками не хуже ступени; в обосновании signals строка «метрики: …». Книга `data/metrics.csv` — ОТДЕЛЬНЫЙ кэш
  `metrics-<run_id>` (блоки в daily/lookup, restore в bot); список путей «Книги (кэш)» не менялся.
- **Результат 13.09** (книга 42 эмитента, числа у ~29): `rank=quality --min-rating A-` пуст — ни у одной бумаги с gap ≥ 0 нет
  премии ≥ 30 б.п. (Медскан, Роснефть, Софтлайн, Фосагро, ИЭК, Лайфстрим торгуются без премии). Единственное имя A с обеими осями в

  собственник Русгаздобыча). Аэрофьюэлз gap −1 при +220…+290 (плата за траекторию), Биннофарм/Алиум gap −1, ЛСР gap −3 при
  расширении z +2.3 (обе оси говорят «рынок знает»).
- **Ограничения оси**: для AAA и госкомпаний (РЖД, Россети, Русгидро, Магнит) разрыв −5…−9 отражает господдержку/масштаб — не

## Дальше по плану пользователя
- Сначала довести сравнение с группой пиров (готово, идёт проверка на живых данных), потом «перебор методологии»:

  расхождение с YTM MOEX; отчётность из ГИР БО — только когда пользователь прогонит `financials fetch --from-screen`
